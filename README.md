### [CIFAR-10 CNN](projects/cifar10-cnn/README.md)

A work-in-progress image classifier with two convolutional layers, dataset
loaders, a seeded training/validation split and a validation helper. CPU/GPU
forward checks and one actual CIFAR-10 batch passed. A training loop and
